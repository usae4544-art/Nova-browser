## Nova Browser v1.0.3

### What's New

• **🌟 Community Reviews & Star Ratings (Liquid Glass UI)**: Interactive 5-star rating with bouncy spring animations and Sakuga micro-sparks. View all verified community reviews, rating distribution breakdown, review comments, and submit or edit your own review.
• **✍️ Sakuga Typewriter / Writing VFX**: Typewriter key strikes, upward ink particle accents, and shimmering glints while typing in search or comments. Expanding liquid meniscus wave when tapping the bottom dock capsule.
• **👤 Persistent User Account System**: Sign in or create a custom profile with display name, bio, and glowing avatar accent colors. Account session persists seamlessly across the entire browser.
• **📥 All-File & Blob Download Support**: Integrated DOM JavaScript bridge (`__novaBlobBridge`) converting in-memory `blob:` URLs into downloads, universal format detection (APKs, ZIP, RAR, 7Z, TAR, GZ, ISO, PDF, DOCX, MP4, MP3, etc.), and MediaStore public storage sync. Added Archives filter in Downloads.
• **🚀 In-App GitHub Auto-Updater**: Bumps version to v1.0.3 with instant notification dialog for all users.
